# TECH DECISIONS

Use Leptos 0.6.15 CSR (MIT) and unicode-normalization 0.1.24 (MIT/Apache-2.0), exact direct pins plus Cargo.lock. This establishes a conservative API baseline; maintenance and vulnerability review remain outstanding. Rust toolchain is pinned to installed 1.100.0. No Burn dependency until a model/operations proof of concept is performed. TF-IDF/logistic regression offers small CPU inference but needs reliable labels and domain-shift evaluation; lightweight neural models add runtime complexity; Indonesian transformers offer contextual features but have larger memory/download requirements; quantization needs equivalence tests; hybrid models require ablation studies. No approach selected as validated. Official docs.rs and Hugging Face requests returned proxy HTTP 403 during audit. No model license verified.

The Cargo package is deliberately a library plus binary rather than an empty multi-crate workspace: this keeps native core tests separate from browser UI without creating unused crates. A future parser/runtime boundary can become separate crates when concrete implementations exist. wasm-bindgen 0.2.105, wasm-bindgen-futures 0.4.55 and web-sys 0.3.82 are pinned together. Their MIT/Apache licensing permits this use; a full transitive license/security audit remains outstanding.
