# SECURITY

No analytics, secrets, external fonts, document upload or persistent document storage. Leptos renders text through escaped text nodes. Input limited to 100,000 characters and file reads to 400,000 bytes. CSP supplied for Pages; Trunk bootstrap hashes are generated by scripts/csp.py; Chromium passed with these headers on a local production-artifact server. Actual Cloudflare deployment remains untested. TXT reads use a generation guard: new selection, text edits and clearing invalidate earlier read results. The underlying bounded File.text read is not aborted. DOCX/PDF are not accepted; ZIP bomb/PDF mitigations are not claimed. Model checksum/cache security not implemented. Dependency vulnerability scan pending.
