# PRD

Research prototype for Indonesian document analysis. Target: a validated local detector, never proof of authorship. Current usable scope: pasted/TXT text and descriptive statistics. Detection is blocked pending trustworthy licensed data, evaluation and browser inference. No login, backend, paid API or publication.

Current product focus: reviewing possible AI-text indications in Perilaku Organisasi practicum reports for Teknik Industri, Universitas Muhammadiyah Malang. Use a simple report form rather than promotional landing-page design. This contextual focus does not establish institutional endorsement or domain-specific validation; the existing experimental model still requires independent evaluation on consented practicum reports before any academic decision-making use.
