Browser smoke test: run `python3 scripts/serve.py` to serve dist with security headers on port 8081, install Playwright in an external tooling directory, then run `node tests/browser.cjs`. Set CHROMIUM_PATH for the browser executable. The managed environment provides Playwright and /usr/bin/chromium. The test checks real WASM mounting, paste/statistics, TXT extraction, invalid content, empty-input error, clearing and mobile overflow. It does not test classifier inference or GPU.

`node tests/model-browser.cjs` exercises bundled trained weights with WebGPU disabled, comparing browser scores to Python-generated numeric references in model-cases.json. These handwritten test texts have no ground-truth authorship labels and are not quality evaluation data. Three local-only held-out corpus records were also tested during integration; corpus text is not committed. `cargo test --locked` includes native bundled-model parity. Browser checks require the production-header server on port 8081.

DOCX browser checks: `python3 tests/make_docx_fixtures.py`, then `node tests/docx-browser.cjs` against scripts/serve.py. Synthetic fixtures are generated in /tmp/nusa-docx, including a ZIP exactly at the 10 MiB upload boundary. Tests verify browser extraction, preview-before-analysis, corrupt/oversized XML, spoofed extension, no external requests and mobile overflow. No user documents are used.
