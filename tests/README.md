Browser smoke test: run `python3 scripts/serve.py` to serve dist with security headers on port 8081, install Playwright in an external tooling directory, then run `node tests/browser.cjs`. Set CHROMIUM_PATH for the browser executable. The managed environment provides Playwright and /usr/bin/chromium. The test checks real WASM mounting, paste/statistics, TXT extraction, invalid content, empty-input error, clearing and mobile overflow. It does not test classifier inference or GPU.
